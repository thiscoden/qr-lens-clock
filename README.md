# QR-Wecker (Arbeitstitel)

Minimalistischer Android-Wecker ohne Snooze und Aus-Knopf, der erst verstummt, wenn du deinen persönlichen QR-Code scannst.

Lernprojekt mit Schwerpunkt auf sauberem Prozess (Spezifikation, Tests, CI, Pull Requests) und strukturiertem Arbeiten mit Claude Code.
